## 🌟 Overview

A modern, high-performance, dark-mode developer portfolio and interactive resume web application built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS / Glassmorphic UI**.

Designed with rich visual aesthetics (subtle violet/indigo radial gradients, glassmorphic cards, smooth animations) and featuring an **integrated ATS-friendly printable resume** with 1-click PDF download.

---

## 🚀 Key Features

- 🎨 **Modern Dark Aesthetics**: Deep slate backgrounds, purple-indigo glowing accents, and smooth glassmorphism.
- ⚡ **Next.js 15 App Router**: Server-side rendering, optimized fonts, fast page loads, and zero layout shift.
- 📱 **Fully Responsive**: Flawless experience across desktop, tablet, and mobile viewports with responsive navigation.
- 💼 **Experience Timeline**: Detailed internships and roles at **OneSpider**, **Elektro Labs**, and **Infobyte.in**.
- 🛠️ **Categorized Technical Skills**: Visual progress bars and skill chips across Languages, Frontend, Backend, Databases, Authentication, Cloud Storage, and QA Automation.
- 📂 **Featured Projects Showcase**:
  - **Parinda** (Full Stack Platform)
  - **CloudVault / ImageKit** (Cloud Asset Management & Media Processing)
  - **Mithaas Bakery** (E-Commerce Web Application)
  - **React Firebase Task Manager** (Real-Time State & Auth)
  - **OrangeHRM Automation Framework** (Selenium, TestNG & Hybrid QA)
- 📄 **ATS-Formatted Resume Modal**: Clean, 1-2 page printable format formatted for ATS readability with print optimization.
- 📬 **Interactive Contact Form**: Direct message dispatch and social link integration.

## 💻 Getting Started Locally

### Prerequisites

- **Node.js**: v18.17.0 or higher
- **npm** or **yarn** or **pnpm**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mauryasapna/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the portfolio.

### Building for Production

To create an optimized production build:
```bash
npm run build
npm run start
```
